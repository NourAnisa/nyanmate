# Install NyanMate on Windows

NyanMate is packaged as a normal Windows desktop application so users do not need Node.js, Rust, Git, or a terminal.

## Recommended installation

1. Open the repository's **Releases** page.
2. Open the latest NyanMate release.
3. Download the file ending in **`setup.exe`**.
4. Double-click the installer.
5. Choose a language and follow the installer steps.
6. Launch **NyanMate** from the Start Menu.

The NSIS installer uses **current-user installation**, so it normally does not need Administrator privileges.

## Alternative installer

An `.msi` package is also generated for users who prefer the standard Windows Installer format.

## Windows SmartScreen

Current development builds are not code-signed yet. Windows SmartScreen may therefore show an **Unknown publisher** warning. Only install builds downloaded from the official `NourAnisa/nyanmate` GitHub Releases page. A signing certificate should be added before a public stable release.

## For developers

To build both Windows installer formats locally on Windows:

```bash
npm install
npm run desktop:build
```

The resulting installer files are generated by Tauri under `src-tauri/target/release/bundle/`.

## Automated release build

The repository includes `.github/workflows/windows-release.yml`. It can be started from **GitHub → Actions → Windows Installer Release → Run workflow**, or automatically by pushing a version tag such as `v0.29.0`.

The workflow builds the app on a Windows GitHub runner, creates a GitHub Release, and attaches both the easy `setup.exe` installer and the `.msi` package.
